# FitZone Gym Website

## Objective
A simple gym and fitness website made for the Web Development MSE project.

## Features
- Home section
- Workout plans
- Fitness programs
- Sample membership plans
- Basic health tips
- Buttons with simple JavaScript interactions
- Responsive layout for smaller screens

## Technologies Used
- HTML
- CSS
- Basic JavaScript DOM using document.getElementById()

## How to Run
1. Download or clone this project.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.
